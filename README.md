# Java Mini Projects

This repository contains small Java console-based projects created for practice and learning.  
Each project focuses on core Java concepts such as variables, input handling, operators, conditional logic, and basic mathematical calculations.

---

## 📂 Projects Included

### 1️⃣ MadLibsGame
A fun Mad Libs game that generates a short story based on user input.

### 2️⃣ FoodieCart
A simple food ordering and billing system that calculates the total cost based on user-selected quantities.

### 3️⃣ CompoundInterestCalculator
A calculator that computes the final amount using the compound interest formula based on user-provided principal, rate, time, and compounding frequency.

### 4️⃣ WeightConverter
A menu-driven program that converts weight between pounds (lbs) and kilograms (kgs).

---

## ▶ How to Run

1. Clone the repository  
2. Open the project in Eclipse or any Java IDE  
3. Navigate to `src/mypackage`  
4. Run any `.java` file to start the program
